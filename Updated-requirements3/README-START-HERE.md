## 💡 KEY INNOVATIONS

### 1. Recovery System
**Problem:** Wrong answers frustrate players, causing dropouts  
**Solution:** Humorous acknowledgment + easier recovery question  
**Result:** Maintains engagement, preserves streaks, keeps it fun

### 2. Personality Profiles
**Problem:** Scores are boring and unmemorable  
**Solution:** 20+ personalities based on play style  
**Result:** High shareability, replay value, collecting behavior

### 3. Secret Employee Detection
**Problem:** Need recruiting pipeline

**Result:** Identifies engaged candidates immediately

### 4. Surprise Questions
**Problem:** Straight trivia gets monotonous

**Result:** Breaks tension, adds delight, increases memorability

## 📊 THE GAME AT A GLANCE

### Structure
- **12 questions** per game
- **4-6 minutes** duration
- **3-4 surprise questions** randomly inserted
- **Recovery questions** after wrong answers
- **Personality reveal** at end

### Question Bank
- **20 Easy** questions (15sec timer)
- **25 Medium** questions (12sec timer)
- **25 Hard** questions (18sec timer)
- **20 Expert** questions (20sec timer)
- **10 Resolve AI** questions (recruiting detection)
- **20 Recovery** questions (encouragement)

### Scoring
- Base points: 100 (easy) to 400 (expert)
- Time bonuses: +25 or +50
- Streak multipliers: 2x, 3x, 5x, 8x
- Max realistic score: ~15,000 points
