## 🎯 DESIGN PRINCIPLES

### 1. Elegant Simplicity
- Clean layouts with generous whitespace
- Young Serif brings sophistication
- Inter provides clarity
- No visual clutter

### 2. Minimal Emoji Usage
- ✅ Use sparingly and only when truly applicable
- ❌ Don't overuse for decoration
- Focus on clean typography and color
- Let the design speak

### 3. Brand Color Dominance
- Olive green (#657220) for primary elements
- Neon yellow (#D9F400) for energy/CTAs
- Off-white (#F8F8F5) for calm backgrounds
- Rich black (#222222) for readability

### 4. Professional Polish
- Smooth 60fps animations
- Subtle transitions
- Thoughtful micro-interactions
- No "cheap game" feel

## 🎨 COMPONENT STYLING

### Buttons

**Primary (CTA):**
```css
background: #D9F400;
color: #222222;
font: Inter SemiBold, 16px;
padding: 12px 32px;
border-radius: 8px;
hover: shadow + slight lift
```

**Secondary:**
```css
background: transparent;
color: #657220;
border: 2px solid #657220;
font: Inter SemiBold, 16px;
hover: background #F8F8F5
```

### Cards

```css
background: #FFFFFF;
```

## ✨ ANIMATION GUIDELINES

### Principles
1. **Smooth & Subtle** - 60fps always
2. **Purposeful** - Every animation has meaning
3. **Olive Accents** - Use brand green for emphasis
4. **Yellow Energy** - Neon yellow for excitement
5. **No Overload** - Don't distract from content

### Key Animations

**Correct Answer:**
- Olive green pulse from edges
- Smooth scale-in for "CORRECT!"
- Subtle celebration (not excessive)
- Points count up with olive color

**Wrong Answer:**
- Gentle fade (no harsh shake)
- Olive messaging (supportive)
- Recovery card slides smoothly
- Encouraging tone throughout

**Personality Reveal:**
- Elegant fade-in
- Young Serif name scales beautifully
- Image frame in olive
- Professional presentation

## 🚫 WHAT NOT TO DO

### Avoid These Mistakes

❌ **Don't use:**
- Random bright colors (blue, purple, red)
- Excessive emojis everywhere
- Comic Sans or playful fonts
- Harsh error states
- Cluttered layouts
- Generic UI patterns

✅ **Do use:**
- Resolve AI brand colors only
- Emojis sparingly (where truly applicable)
- Young Serif + Inter consistently
- Supportive feedback
- Clean, spacious layouts
- Distinctive brand identity
