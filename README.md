# Resolve AI Trivia Game

A React + TypeScript trivia game built for AWS re:Invent.

## Features
- **Dynamic Question Bank:** 100+ questions across technical and fun categories.
- **Personality System:** Determines player personality based on performance.
- **Responsive Design:** Optimized for mobile, tablet, and laptop screens.
- **Recovery Mode:** Special questions to save your game when you're doing poorly.

## Tech Stack
- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Zustand

## Development

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Deploy to GitHub Pages
```bash
npm run deploy
```
